Database — Backup & Restore

Auto-save now keeps your data in this browser automatically (see the Auto-Save panel on the Dashboard) — closing the tab or refreshing will no longer lose your records on this same device/browser. However, this browser storage can still be cleared by clearing browser data, and it does not transfer to another device. For that, use Backup Database regularly to download a portable file, and Restore Database to load a saved file back into the system (this replaces all current data — export a fresh backup first if unsure). "Export All Data (.xlsx)" puts every record type into one Excel file for viewing/printing and is not meant for restoring.
